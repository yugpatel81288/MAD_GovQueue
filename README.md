# GovQueue

### Know Before You Go.

GovQueue is an Android application that helps citizens check
government office information and estimated crowd conditions
before visiting.

## Features

- User Registration & Login
- Forgot Password
- Government Office Search
- Nearby Offices
- Office Details
- Crowd Status
- Estimated Waiting Time
- Citizen Crowd Reporting
- Reports History
- Profile & Logout

## Technology

- Kotlin
- XML
- Android Studio
- SQLite
- Material Design

## Scope

This is an academic MVP demonstrating a citizen-focused
government office crowd-information system.
